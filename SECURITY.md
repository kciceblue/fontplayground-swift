# Security policy

Font Playground runs entirely on your Mac and makes no network requests. If you find a security problem, such as a font file that makes the app or its font engine run code or write outside the folders it should, please report it privately: on GitHub, open **Security › Report a vulnerability** in this repository. Don't open a public issue for it.

Please include the Font Playground version, your macOS version, and the steps to reproduce. Only the latest release receives fixes.

如发现安全问题，请在本仓库的 **Security › Report a vulnerability** 中私下报告，不要公开提交 issue。
