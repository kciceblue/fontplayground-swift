# v1.0.0 parity sign-off (WP-701)

Commit hashes and pull request numbers here (`c8a9523`, `abcc305`, #37, #47 and so on) refer to the development history. It stays private, and the public repository starts with a single commit of the 1.0.0 sources.

**Status: signed off on candidate 1.0.0 (4), 2026-09-30.** Every row below passes on the release candidate (AC-701-1). Candidate 1.0.0 (1) was driven in full. Its findings A–D were fixed in 1.0.0 (3), and the live recheck of 1.0.0 (3) confirmed them but found G and H. Those are fixed in **1.0.0 (4)**, and A–D, G and H were all rechecked live on it. Checks that need a person are signed off by the maintainer (see Manual acceptance results).
