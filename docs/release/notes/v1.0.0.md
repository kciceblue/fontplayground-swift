Font Playground combines fonts on your Mac into one font. Choose a main font for letters and numbers, add fonts for other languages, see which font draws each character, then install the result or save it as a `.ttf` file.

This is the first release of the native Mac app. It replaces the earlier Windows version.

简体中文说明见下文。

## Download

- Download `FontPlayground-1.0.0-arm64.dmg`, open it, and drag Font Playground to Applications.
- Requires a Mac with Apple silicon and macOS 14 Sonoma or later.
- Signed with a Developer ID and notarized by Apple.
- To check the download, put `FontPlayground-1.0.0-arm64.dmg.sha256` in the same folder and run `shasum -a 256 -c FontPlayground-1.0.0-arm64.dmg.sha256`.

## What you can do

- Choose a main font, then add fonts for Chinese, Japanese, Korean, Arabic, Thai and other languages.
- Type your own text in a preview drawn exactly as the result will draw it. Colour by Font shows which font draws each character, and characters no font can draw are listed with a way to find one.
- Adjust the size and weight of each added font. Variable fonts are built at the weight you choose.
- Install the result for your user account, or save a copy as a `.ttf` file. Font Playground never replaces a font it didn't install.
- Use Advanced to see which font draws each script, choose the font that sets line spacing, and read the build report.
- Use the app in English or Simplified Chinese.
- Import your last recipe from the Windows version.

Everything runs on your Mac. Python and the font engine are included, and the app collects no data.

## Known limitations

- Apple silicon only.
- No whole-family builds, glyph editing, cross-font kerning, colour emoji, or per-language variants of shared Chinese, Japanese and Korean characters.
- Fonts that rely on Apple AAT shaping for a complex script can't be merged for that script.
- This release was tested on macOS 27. If something doesn't work on an earlier supported version, please open an issue.

Fonts bundled with macOS or Microsoft products are licensed for use on your own Mac only. Never share a font forged from them.

## 简体中文

字体混搭可以把你 Mac 上的多个字体合成为一个字体。为字母和数字选择一个主字体，为其他语言添加字体，查看每个字符由哪个字体绘制，然后安装结果，或将它存储为 `.ttf` 文件。

这是原生 Mac 应用的首个版本，取代了之前的 Windows 版。

### 下载

- 下载 `FontPlayground-1.0.0-arm64.dmg`，打开它，然后将字体混搭拖到“应用程序”文件夹。
- 需要搭载 Apple 芯片、运行 macOS 14 Sonoma 或更高版本的 Mac。
- 使用 Developer ID 签名，并经过 Apple 公证。
- 如需校验下载的文件，请将 `FontPlayground-1.0.0-arm64.dmg.sha256` 放在同一文件夹中，然后运行 `shasum -a 256 -c FontPlayground-1.0.0-arm64.dmg.sha256`。

### 功能

- 选择主字体，再为中文、日文、韩文、阿拉伯文、泰文等语言添加字体。
- 在预览中输入你自己的文字，预览效果与最终结果完全一致。“按字体着色”会显示每个字符由哪个字体绘制；没有字体能绘制的字符会被列出，并提供查找字体的方法。
- 调整每个添加字体的大小和字重。可变字体会按你选择的字重生成。
- 为你的用户账户安装结果，或将副本存储为 `.ttf` 文件。字体混搭绝不会替换不是由它安装的字体。
- 在“高级”中查看每种文字由哪个字体绘制，选择决定行距的字体，并阅读生成报告。
- 界面支持英文和简体中文。
- 可以导入 Windows 版中的上次方案。

所有处理都在你的 Mac 上完成。Python 和字体引擎已包含在内，应用不收集任何数据。

### 已知限制

- 仅支持 Apple 芯片。
- 不支持一次生成整个字族、字形编辑、跨字体字距调整、彩色表情符号，以及中日韩共用字符的按语言变体。
- 对于复杂文字依赖 Apple AAT 排版的字体，无法在这些文字上合并。
- 报告中有些说明来自字体引擎，会以英文显示。
- 此版本在 macOS 27 上测试。如果在其他受支持的较早版本上遇到问题，欢迎提交 issue。

随 macOS 或 Microsoft 产品附带的字体仅许可在你自己的 Mac 上使用。切勿分享由它们合成的字体。

### 支持字体混搭
